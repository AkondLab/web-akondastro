Observatory optimized FITS Images viewer with advanced analysis tools for professional astronomical observation workflows.

**Key Features:**
- **Radial Profile Analysis** - Press R key for instant star profile with Gaussian fit, FWHM, RMS, and sky level measurements
- **Linear Profile Tools** - Quick keyboard shortcuts (H/V/D keys) for horizontal, vertical, and diagonal intensity profiles with real-time statistics
- **WCS Support** - Full World Coordinate System integration for accurate celestial coordinate display
- **Directory Scanning Mode** - Real-time monitoring of observatory directories with automatic loading of new FITS files, essential for live observing sessions
- **Integrated IPython Console** - Direct access to image data, headers, and WCS for custom analysis and scripting
- **Flexible Layout** - Customizable dock widgets with pinnable FITS header cards for personalized workflow
- **Real-time Statistics** - Continuous display of image statistics in status bar for quick quality assessment
