Together with the Araucaria Project team,
we are developing the OCM Observatory software platform.

Telescope automation, modern observatory GUI, data processing pipelines and machine learning tools are the components which
make **OCM** a powerful tool for astronomical research.

## Overview

The **OCM Observatory** (Optical Gravitational Lensing Experiment Control & Monitoring) is a comprehensive software platform designed for modern astronomical observatories. Built in collaboration with the Araucaria Project team at CAMK (Nicolaus Copernicus Astronomical Center), OCM represents the next generation of observatory control systems.

## Key Features

### Telescope Automation
- Full remote control capabilities for telescope operations
- Automated observation scheduling and execution
- Weather monitoring and automatic safety protocols
- Coordinated multi-telescope support

### Modern Observatory GUI
- Intuitive web-based interface accessible from anywhere
- Real-time monitoring of telescope status and observations
- Interactive sky charts and target planning tools
- Comprehensive logging and diagnostics

### Data Processing Pipelines
- Automated image calibration and reduction
- Photometry and astrometry processing
- Quality assessment and validation
- Integration with astronomical databases

### Machine Learning Tools
- Automated object detection and classification
- Variable star identification
- Anomaly detection in observation data
- Predictive maintenance for equipment

## Technology Stack

OCM is built using modern, robust technologies:

- **Backend**: Python-based architecture with FastAPI
- **Frontend**: Modern web technologies for responsive UI
- **Database**: PostgreSQL for reliable data storage
- **Real-time Communication**: WebSocket integration for live updates
- **Hardware Control**: ASCOM/INDI driver compatibility

## Universal Platform

The platform is designed with flexibility in mind, making it suitable for:

- Professional research observatories
- University teaching facilities
- Amateur astronomy clubs
- Remote robotic telescope networks

## Deployment

OCM is currently in active use at the Araucaria Project's facilities in Chile and has been successfully deployed at several observatories worldwide.

For more information, visit the [OCM Observatory website](https://ocm.camk.edu.pl).
